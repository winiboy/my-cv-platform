Decision (a), en behaviour change sanctioned by the PRD: on a duplicate save the API answers 409 with isDuplicate:true, which the client used to drop, so every locale showed the server's English "Job already saved" as an error toast and the button stayed on "Save". The PRD lists jobAlreadySaved with "en = today's fallback", and that fallback was unreachable. The flag is now passed through: the localized info toast shows ("This job is already in your saved applications." in en) and the button shows "Saved". Rejected: leaving the bug, which keeps English in fr/de/it on that path.

Decision (b), en text change sanctioned by the PRD: the two "could not load resumes" toasts in job-detail-panel.tsx used a key whose en text was "Please create a CV first."; the PRD Context names exactly this. They now read resumeSelector.loadError, en "Failed to load resumes" (the selector modal's existing literal). Error path only.

Decision (c), stored data: the POST to /api/job-applications builds location from the localized "{city}, Switzerland" template (the PRD lists that line), so a French save stores "Lausanne, Suisse". This contradicts the PRD's Impact Assessment "Database / persistence: Not affected". en stores the same value as before; duplicate detection keys on job_url, so no duplicates can result; listings with location_full were already stored as given by the feed.

Decision (d), en byte-identity where the old output depended on the browser: allJobsLoaded count and the selector's "Updated" date keep the bare toLocaleString()/toLocaleDateString(undefined) in en and use the page locale in fr/de/it; card and detail dates keep "en-GB" in en (the old literal). src/lib/job-search-format.ts documents each branch.

Decision (e), saving label: no natural French word for "saving" fits the 85px cell at 375px ("Enregistrement…" needs 115px, "Sauvegarde…" 93px), so fr reads "En cours…"; it "Salvando…" (code-reviewer finds it less idiomatic than "Salvataggio…", which needs 91px). Rejected: changing the button layout, which would also change en.
