Decision (orchestrator): the order is deadline → rate limit → page fetch. A past deadline costs no AI budget. The per-user AI limit caps how often a user can make the server fetch job-board pages. A removed page costs one unit, and an already-limited user whose offer page is gone sees the rate-limit error rather than the closed-offer message.
Decision (implementer): safeFetch only does GET, so the checker sends GET with fetch-external's headers and cancels the body once the status is known; safeFetch's shared options were not extended with HEAD.
Decision: only a final 404 or 410 closes the offer. A refused URL, a timeout, a network error and every other status leave it open, as the owner decided on 2026-10-23.
