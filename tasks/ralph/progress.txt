### US-001: Audit HTML tag leakage points in Modern CV
- Status: PASS
- Commit: (audit only — no code changes)
- Priority: 1

#### Audit Findings

**ROOT CAUSE:** Modern template preview uses `formatText()` (plain-text parser) instead of `renderFormattedText()` (HTML-aware parser) for fields that store HTML from RichTextEditor.

**Field → Rendering → Surface → Risk:**

| Field | Preview Function | DOCX Function | Risk |
|-------|-----------------|---------------|------|
| resume.summary | formatText() @ line 533 | parseHtmlToDocxRuns() | HIGH — tags leak in preview |
| exp.description | formatText() @ line 619 | parseHtmlToDocxRuns() | HIGH — tags leak in preview |
| exp.achievements[] | formatText() @ line 647 | manual decode+strip @ 1191-1197 | MEDIUM — tags leak in preview |
| project.description | raw {interpolation} @ line 1022 | parseHtmlToDocxRuns() | HIGH — tags leak in preview |
| skillCategory.items | direct render @ line 389 | TextRun (plain text) | NONE — plain text |
| skillCategory.skillsHtml | NOT USED in preview | parseHtmlToDocxRuns() @ 737-769 | MISMATCH — DOCX reads HTML, preview reads items |

**Surface equivalence:**
- PDF = browser print of preview → same leakage as preview
- Apercu = same component as preview → same leakage as preview
- DOCX = separate pipeline → mostly correct, minor improvement possible for achievements

**Fix strategy:**
- Preview/Apercu/PDF: Replace `formatText()` with `renderFormattedText()` for summary, description, achievements. Wrap project.description in `renderFormattedText()`.
- DOCX: Consider using `parseHtmlToDocxRuns()` for achievements instead of manual decode+strip.
