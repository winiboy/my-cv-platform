Decision (FR-1): keep every modal string in jobs.json and build a typed object on the server for each caller. Rejected:
- moving cvAdaptation into common.json, which would mean a second namespace or a large move;
- loading all of `jobs` on the editor page, which ships an untyped, larger payload with no missing-key check.
The cost of the chosen approach: a missing key makes the page return 500 instead of showing English. That is accepted: the PRD forbids English fallbacks, the dictionaries are static JSON, and the unit test checks every locale.
