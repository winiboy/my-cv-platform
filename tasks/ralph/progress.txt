Decision (AC-02, AC-10): thumbnails draw only after the window is measured (ResizeObserver; scale is null on the server and in the first client render), because a CSS transform cannot divide two lengths. Server and first client render are therefore identical. Rejected: a fixed scale (wrong at each breakpoint) and CSS zoom (non-standard layout effects). The reason is recorded in template-picker.tsx.
Decision (unit-test layer): vitest runs in node with no jsdom/testing-library, and adding dependencies is out of scope (frontend rule, FR-7). Picker structure is therefore unit-tested with react-dom/server, which also proves the server render. Interaction (keyboard, click, focus) is proven in the Playwright e2e.
